# 🌩️ CloudPulse V20 - Inteligência Competitiva

O **CloudPulse** é uma plataforma avançada de Inteligência Competitiva que utiliza uma **Arquitetura de IA Multiagente Enterprise** para monitorar, analisar e validar dados de mercado e estratégias de concorrentes em tempo real.

## 🚀 Arquitetura Multiagente

O núcleo do sistema foge dos padrões tradicionais de scripts simples. Ele é guiado por um design pattern de *Orchestrator*, que delega tarefas para agentes de Inteligência Artificial especializados:

- 🧠 **CloudPulse Orchestrator & Supervisor:** Coordenam todo o fluxo de ponta a ponta, recebendo o pedido do usuário e acionando os especialistas.
- 🕷️ **Crawler Agent:** Realiza web scraping inteligente e em tempo real nos sites dos concorrentes.
- 💰 **Finance Agent:** Analisa e estrutura dados financeiros, mapeando preços, descontos e promoções.
- 📊 **Report Agent:** Consolida todas as informações mineradas em um dossiê executivo claro.
- 🛡️ **Self-Correction Agent:** Audita os dados gerados pelo relatório, caçando inconsistências e inserindo avisos automáticos de confiabilidade antes da entrega final (blindagem contra alucinações).

## ☁️ Integração AWS Cloud
O sistema possui integração nativa com os serviços em nuvem da Amazon:
- **Amazon Bedrock:** Motor de IA Generativa para processamento avançado do histórico.
- **Amazon S3:** Armazenamento seguro de coletas (Data Lake) para comparações de tendências.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Frontend:** Streamlit
- **Nuvem:** AWS SDK (Boto3)
- **Design:** Multi-Agent Architecture
